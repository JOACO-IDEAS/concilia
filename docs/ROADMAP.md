# Roadmap

## Now

1. Keep the repository gate green and the canonical docs synchronized with code.
2. Harden and productize the ConcilIA Agent's read-only operational and document-search experience.
3. Clarify or retire the remaining overlap between legacy mock surfaces and database-backed workflows.
4. Re-establish fixture and production migration state through the read-only preflight before any release planning.

## Next

- Implement durable, organization-scoped product-event observability under `PRODUCT_OBSERVABILITY_CONTRACT.md`.
- Continue calibrating evidence and identity signals while retaining human-review gates and decision provenance.
- Expand integration contracts and failure handling without making provider credentials a local-development requirement.
- Improve onboarding, tenant administration, and operational exception workflows.

## Later / north star

- Proactive operational assistance that completes supported work and escalates only genuine exceptions.
- Broader source-system integration while remaining an operational layer above incumbent ERPs.
- Carefully governed automation based on measured calibration, reversibility, and auditability.

Production migrations, deployments, customer-data access, and real outbound communications are approval-gated operations, not roadmap tasks an agent may execute autonomously.
